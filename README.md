> **PayPulse AI** is a high-throughput FinTech fraud analytics platform designed for the Indian payment ecosystem (UPI, Credit Cards, NetBanking, BNPL). It evaluates 15,000+ simulated transactions/second with sub-15ms latency, features an interactive Razorpay/UPI payment sandbox, sliding-window velocity rule engine, and an embedded LLM-powered Financial Copilot.

---

## 🌟 Key Features

### 1. 📡 Live Fraud Radar & Streaming Engine
- Real-time simulated ingestion of Indian market payment streams (Swiggy, Zerodha, CRED, Flipkart, Zomato, Meesho).
- Threat vector inspection: TOR exit node detection, jailbroken/rooted device fingerprinting, proxy detection, and ML risk scoring (0-100%).

### 2. 🤖 Conversational AI Financial Copilot
- Natural language RAG assistant for compliance officers and fraud investigators.
- Instant 1-click audit prompt chips for automated audit summaries.

### 3. 💳 Razorpay & UPI Payment Gateway Sandbox
- Interactive payment checkout simulator (GPay, PhonePe, Paytm UPI, HDFC Regalia Cards, Simpl BNPL).
- Live threat vector injection: Toggle proxy IPs, high-velocity retry spikes, or night-time high-value transfers.
